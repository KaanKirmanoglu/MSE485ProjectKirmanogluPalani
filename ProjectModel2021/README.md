# Project Title: Parallel MC model for Langmuir-Hinshelwood mechanisms of oxygen on carbon surfaces
MSE 485 - Atomistic Scale Simulations - Course, Fall 2021 Final Project by Kaan Kirmanoglu and Kevin Palani

### Project Aim
* Write a Monte Carlo code that simulates a given number of competing Langmuir-Hinshelwood mechanisms
* Predict steady-state surface coverage as a function of temperature and incident particle flux
* Predict the oxidation probability of carbon (# reactions/# surface-particle collisions)
* Implement FPGA parallelism to minimize computer run times.
